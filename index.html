PERSONAL MARKET MONITOR · 个人市场监测

一封克制、透明的
每周市场周报

Weekly Market Report 是一项仅供所有者个人使用的自动化服务。它汇总公开市场数据，生成中文 HTML 周报与 CSV 附件，并通过 Gmail API 发送给唯一指定的收件人。

个人使用 每周发送 只请求 gmail.send 不读取邮箱

01 / 报告内容

覆盖什么

报告用于回顾价格表现和观察市场广度，不提供个性化投资建议、交易指令、目标价或收益承诺。

核心资产

QQQ、JEPQ、SPY、GLD 与 BTC/USD 的本周、近四周及年初至今回报。

主要股票

美国主要上市公司、七大科技股，以及标普 500 周涨幅前十和后十。

科技观察池

依据公开、固定且可复核的质量增长规则进行筛选，不生成荐股评分。

数据质量

缺失、冲突或无法核验的数据会标记为 N/A 或排除，不会猜测为零。

02 / GOOGLE DATA ACCESS

最小化 Gmail 权限

https://www.googleapis.com/auth/gmail.send

应用只使用这一项权限来发送由程序生成的市场周报和故障提醒。它不会读取、搜索、下载、修改或删除 Gmail 邮件，也不会访问联系人、日历或 Google Drive。

查看完整隐私政策

03 / 工作方式

从公开数据到私人邮件

  1. 01
    获取市场数据

    使用公开或已授权的数据源读取行情、成分和公司申报数据。

  2. 02
    生成报告

    计算固定口径的回报与筛选结果，并生成 HTML 和 CSV。

  3. 03
    发送给单一收件人

    通过 Gmail API 发出邮件；程序在发送边界禁止抄送、密送或其他收件人。

重要说明

这是一项个人信息工具，不是投资顾问。

市场数据可能延迟、不完整或存在调整差异。使用者应独立核验信息，并自行承担任何投资决定的风险。

ENGLISH SUMMARY

A private, single-user weekly market report

Weekly Market Report compiles public market information into a Chinese HTML email and CSV attachment. It uses only the Gmail gmail.send scope to deliver owner-generated reports to one preconfigured recipient. It does not read, search, modify, or delete Gmail content and is not an investment-advisory service.
