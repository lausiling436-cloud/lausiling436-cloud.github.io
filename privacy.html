PRIVACY POLICY · 隐私政策

数据使用保持最小、明确且可撤销。

生效日期：2026 年 10 月 9 日

摘要

只发送，不读取。

只服务一个所有者和一个预配置收件人。

不出售 Google 用户数据。

1. 应用范围

Weekly Market Report 是一项个人、非商业、单用户的自动化工具。它汇总市场信息并通过 Gmail API 发送每周报告与必要的运行故障提醒。本政策仅适用于该应用对 Google 用户数据的处理。

2. 请求的 Google 权限

应用只请求 https://www.googleapis.com/auth/gmail.send。该权限仅用于以授权 Gmail 账号发送由应用生成的邮件。

应用不会读取、列出、搜索、下载、修改或删除 Gmail 邮件；不会读取草稿、标签、联系人或邮箱设置；也不会请求 Google Drive、日历或其他 Google 产品的数据。

3. 处理的数据

为完成发送，应用处理授权凭据（OAuth 客户端信息和刷新令牌）、由所有者配置的发件地址、预配置收件地址、应用生成的邮件正文与 CSV 附件，以及 Gmail API 返回的邮件标识符和发送结果。

OAuth 刷新令牌保存在私有 GitHub 仓库的加密 Actions Secret 中，仅在自动化运行时提供给发送步骤。客户端机密和刷新令牌不会写入公开网页、源代码、报告或普通日志。

4. 数据用途

Google 用户数据仅用于鉴权、发送预配置的每周市场周报或故障提醒、防止重复发送，以及记录最低限度的发送状态。数据不会用于广告、画像、信用评估、出售或与应用目的无关的分析。

5. 数据共享

应用不会出售、出租或向数据经纪商分享 Google 用户数据。发送流程由 GitHub Actions 执行，并直接调用 Google Gmail API；除提供运行基础设施和邮件发送服务所必需的处理外，不会向其他市场数据提供商披露 Google 用户数据。

6. 保留与删除

刷新令牌会保留到所有者撤销 Google 授权、删除相应 GitHub Secret 或停用应用为止。发送状态和 Gmail 返回的邮件标识符保存在私有仓库，用于防止重复投递和排查失败。已发送邮件由 Gmail 根据授权账号的设置保留。

所有者可以随时在 Google 账号的第三方访问设置中撤销本应用权限，并可删除 GitHub Secrets、私有报告和发送状态。撤销后，应用将无法继续发送邮件。

7. 安全措施

应用遵循最小权限原则，只使用 gmail.send；代码和运行归档保存在私有仓库；敏感凭据通过加密 Secrets 注入；发送边界在代码中限制为唯一收件人且禁止抄送和密送。任何网络服务都无法保证绝对安全，但应用采取与其个人使用范围相称的保护措施。

8. Google API Limited Use

Weekly Market Report's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

9. 儿童隐私与政策变更

本应用并非面向儿童，也不会主动收集儿童信息。如果处理方式发生实质变化，本政策将先行更新，并在需要时重新取得授权。

10. 联系方式

如对本政策或授权有疑问，请使用 Google OAuth 同意页面中显示的“用户支持邮箱”联系应用所有者。

English summary

This personal, non-commercial app uses only the Gmail gmail.send scope to send owner-generated market reports and operational alerts to one preconfigured recipient. It does not read or modify mailbox content. OAuth credentials are stored as encrypted GitHub Actions secrets and are used only during the delivery step. Google user data is not sold, used for advertising, or disclosed to market-data providers. Access can be revoked at any time from the owner's Google Account.
